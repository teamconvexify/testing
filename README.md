# Convexify Tech - Test Project

This is a premium boilerplate for testing GitHub connection and initial setup for the Convexify Tech web application.

## Technologies Used
- **HTML5 & CSS3**: Custom dark mode design with glassmorphism.
- **JavaScript**: Interactive UI elements.
- **Git & GitHub**: SSH Authentication.

## Setup
1. Clone the repository.
2. Open `index.html` in your browser.
3. Make changes and push to GitHub.
